# PersonalityQuizC211
A Java-based personality quiz that determines whether a user is an introvert or extrovert based on their answers to multiple choice questions.
## Contributors
- Myah Hall
- Seth Horban

## Class Distribution
## Myah Hall
- PersonalityType.java - Represents the different personality types and stores their names and descriptions.
- Choice.java - Represents an answer choice and associates it with a personality type.
- Question.java - Stores quiz questions and their available answer choices. 

## Seth Horban
- PersonalityScore.java - Stores the score associated with a personality type.
- Personality.java - Manages the personality scores used to determine quiz results.
- Test Code - Runs the personality quiz and tests how the classes work together.
